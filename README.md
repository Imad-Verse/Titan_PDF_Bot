# 🚀 Titan PDF Bot System
### النظام المتكامل لإدارة وتحويل ملفات PDF عبر تيليجرام

[![Python](https://img.shields.io/badge/Python-3.8+-blue.svg)](https://www.python.org/downloads/)
[![Telebot](https://img.shields.io/badge/Library-pyTelegramBotAPI-green.svg)](https://github.com/eternnoir/pyTelegramBotAPI)
[![License](https://img.shields.io/badge/License-Private-red.svg)](LICENSE)

**Titan PDF Bot** هو بوت تيليجرام متطور ومبني باحترافية للتعامل مع ملفات PDF (تحويل، دمج، تعديل) مع نظام إدارة شامل (Admin Panel) وإحصائيات دقيقة.

---

## 🌟 المميزات الرئيسية | Key Features

### 👤 للمستخدمين (User Features):
- **🖼️ الصور إلى PDF:** تحويل مجموعة صور إلى ملف PDF واحد بجودة عالية.
- **📄 تحويل المستندات:** دعم تحويل ملفات Word (.docx) و الصور إلى PDF.
- **🛠️ أدوات PDF:** (قريباً) دمج، تقسيم، وحماية الملفات.
- **📊 إحصائيات شخصية:** تتبع عدد العمليات وحجم البيانات المعالجة.
- **🔔 نظام اشتراك إجباري:** التأكد من انضمام المستخدم لقنواتك قبل الاستخدام.

### ⚙️ للمديرين (Admin Features):
- **📊 لوحة تحكم شاملة:** عرض إحصائيات المستخدمين والعمليات الحية.
- **📢 نظام إذاعة متطور:** إرسال رسائل (نص، صور، ملفات) لجميع المستخدمين بضغطة واحدة.
- **🚫 إدارة الحظر:** حظر/فك حظر المستخدمين بسهولة عبر المعرف.
- **💾 نسخ احتياطي:** إنشاء نسخة من قاعدة البيانات وإرسالها للمدير فوراً.
- **🔧 وضع الصيانة:** إيقاف البوت مؤقتاً لإجراء التحديثات.
- **🔄 إعادة تشغيل ذكية:** إمكانية إعادة تشغيل البوت مباشرة من التليجرام.

## 🛠️ التثبيت والتشغيل | Installation

### 1. المتطلبات (Requirements):
- Python 3.8+
- معرف بوت من [@BotFather](https://t.me/BotFather)

### 2. تنصيب المكتبات:
```bash
pip install -r requirements.txt
```

### 3. إعداد البيئة:
قم بنسخ ملف `.env.example` إلى ملف جديد باسم `.env` وقم بتعبئة البيانات:
```env
PDF_BOT_TOKEN=توكن_البوت_هنا
ADMIN_ID=معرف_المدير_الرئيسي
ADMINS=معرف_المديرين_مفصولين_بفاصلة
ADMIN_USERNAME=@يوزر_المدير
REQUIRED_CHANNELS=@قناة1,@قناة2
```

### 4. التشغيل:
```bash
python main.py
```

## 📂 هيكلة المشروع | Project Structure

```text
titanpdf-bot/
├── main.py                # نقطة الانطلاق

├── storage/               # تخزين البيانات والملفات المؤقتة (مخفي)
└── logs/                  # سجلات النظام (مخفي)
```
